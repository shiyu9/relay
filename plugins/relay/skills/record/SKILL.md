# record: いまこのセッションを記録する

relay の記録は普段、**次のセッションが起動したとき**に走る。このスキルはそれを前倒しして
いま実行する。起動待ちと違い、**いま動いているこのセッション自身も対象に入る**。

## 手順

### 1. トークンを1つ作る

このセッションの transcript を特定するために使う。形式は日付・時刻・ランダムな英数字4文字を
つないだもの。

- **毎回新しく作ること。**同じ値を使い回すと過去の transcript にも残っていて、
  どれがいまのセッションか決められなくなり、記録が中止される
- **会話に書いた値・他のセッションへ送った値を再利用しない。**同じ理由

### 2. スクリプトを1回実行する

```bash
python "${CLAUDE_SKILL_DIR}/../../scripts/relay_record.py" --cwd "<プロジェクトの絶対パス>" --self <トークン>
```

**この1行を、そのまま1つのコマンドとして実行すること。**`cd` を前に付けない・`&&` や `;` で
他のコマンドとつながない・`2>&1` などを足さない（つないだ形は auto mode の分類器に拒否される。実測）。

`${CLAUDE_SKILL_DIR}` はこのスキル自身のディレクトリに展開される（プラグインルートではない）。
展開されず文字列のまま残る環境では、`**/relay/scripts/relay_record.py` を検索してそのパスを使う。

### 3. 出力された手順を実行する

スクリプトが記録の手順を印字する。**その手順をそのまま実行する。**手順の外のことはしない。

- **「このセッション自身は特定できませんでした」**と出たら、手順1に戻って別のトークンで
  1度だけやり直す。それでも同じなら、このセッションの記録は次の起動に任せ、
  印字された残りの手順を進める
- **「記録するセッションはありません」**と出たら、何もせず終わる

## 書き先

このスキルが変更するのは relay の記録だけ:

| ファイル | 何が起きるか |
|---|---|
| `diary/YYYY-MM-DD.md` | セッションごとの記録を追加・差し替え |
| `knowledge/pitfalls.md` `workflow.md` | 追記と重複の統合 |
| `knowledge/current.md` `decided.md` | 上書き |
| `tasks.md` | **完了したタスクを消すだけ。**項目は足さない |

**それ以外のファイルは変更しない。**
